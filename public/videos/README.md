# Videos Folder

## 📁 Yaha Videos Upload Karo

Is folder me apni sab videos rakho.

### Example:
- `demo-video.mp4`
- `portfolio-video.mp4`
- `background-video.mp4`

### Video Format:
- **Format:** MP4 (H.264 codec)
- **Audio:** AAC
- **Resolution:** 1080p ya 720p recommended
- **File Size:** Under 50MB (web ke liye optimize karo)

### Usage:
Videos ko is folder me rakho aur `App.jsx` me path use karo:
```jsx
demoVideoUrl="/videos/your-video-name.mp4"
```
