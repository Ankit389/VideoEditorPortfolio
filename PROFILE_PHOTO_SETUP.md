## 📁 **Photo Add Karne Ka Tarika:**

### Step 1


   - Ya koi bhi naam, phir `HeroNoRouter.jsx` me update karo

---

### Step 2: Photo Path Check Karo

`src/components/HeroNoRouter.jsx` me line ~100 pe photo path already set hai:
```jsx
src="/images/profile-photo.jpg"
```

Agar photo ka naam different hai, toh update karo:
```jsx
src="/images/your-photo-name.jpg"
```

## 📐 **Photo Specifications:**

### Recommended:
- **Size:** 500x500px ya 800x800px (square)
- **Format:** JPG (best quality) ya PNG (transparent background)
- **File Size:** Under 500KB
- **Aspect Ratio:** 1:1 (square) - best results

### Photo Edit Karne Ke Liye:
- **Online:** Canva, Remove.bg (background remove)
- **Desktop:** Photoshop, GIMP
- **Mobile:** Snapseed, VSCO

---

## ✅ **Quick Steps:**

1. Photo file `public/images/` folder me rakho
2. Photo ka naam `profile-photo.jpg` rakho (ya `HeroNoRouter.jsx` me update karo)
3. Server restart karo: `npm run dev`
4. Website me photo dikhna chahiye!

## ❌ **Agar Photo Nahi Dikhe:**

### Problem 1: Photo Load Nahi Ho Raha
**Solution:**
- Photo file `public/images/` folder me hai ya nahi check karo
- Photo ka naam sahi hai ya nahi verify karo
- File format check karo (JPG, PNG, WebP)

### Problem 2: Photo Blur Hai
**Solution:**
- Higher resolution photo use karo (800x800px ya zyada)
- Photo quality check karo

### Problem 3: Photo Square Nahi Hai
**Solution:**
- Photo ko square crop karo
- 1:1 aspect ratio use karo
